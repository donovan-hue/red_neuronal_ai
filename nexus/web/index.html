Cómo piensa

1. Plan: clasifica la tarea (calcular / buscar / deducir).
2. Acción: delega la aritmética a la calculadora o a un intérprete Python aislado.
3. Observación: lee el resultado real, no lo inventa.
4. Autoconsistencia: muestreos múltiples y voto; el desacuerdo baja la confianza.
5. Verificador: un pase crítico que puede forzar una corrección.
6. Memoria: guarda trayectorias correctas y las reutiliza como ejemplos.
